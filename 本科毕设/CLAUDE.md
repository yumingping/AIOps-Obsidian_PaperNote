## 命名规范

- 论文文件夹：`论文N中文短名`，N 在本科毕设内全局唯一（1–12），中文短名 ≤ 12 字。
- 笔记文件：`N中文短名.md`，与文件夹同名。规范类资料用 R 序号（R1、R2…全局唯一），文件夹 `规范R短名`，笔记 `R短名.md`；规范笔记不配思维导图 canvas、不建论文文件夹口径的 Fig 图，章节页码引用规范物理页码。
- 图：`N-FigK_pP.png`，P 用 PDF 物理页码（第 1 页 = p.1）；期刊印刷页码在笔记正文标注。
- 不新建「概念汇总」类页面；概念链接只指向 vault 内已存在的页面，无对应页面时用粗体术语。

## 笔记规范（每篇一篇 md）

1. 开头元信息：标题（英文原文+中译）/ 作者 / 期刊·会议 / 发表年份；标注页码口径（物理页码 or 印刷页码）。
2. 正文按**论文页码顺序**组织：`## 一、preview（p.X）`、`## 二、introduction（p.X–Y）`……每节标注页码范围。
3. 关键定义/机制按「**含义** + **为什么需要**」两点式记录；核心结论加粗；公式用 `$...$`。
4. 关键图嵌入 vault：`![[N-FigK_pP.png]]` + 斜体图注 `*图X（p.Y）：一句话*`。
5. 每篇结尾两节：
   - **与其他论文的关系**：区块内关系 + 跨区块关系（用 `[[]]` 双链指向其他论文笔记）；
   - **对毕设的帮助**：分三小块给具体条目——①写论文：能用在哪一章、可引用的结论/数字；②动手实现：能直接借鉴的机制、参数、设计取舍；③测试：可模仿的实验设计、指标口径。
6. 术语浅显化（面向研0 读者）：
   - 技术名词/缩写**首次出现**时，括号内给一两句浅显中文解释（可用生活类比），并加 `[[概念名]]` 双链指向概念汇总页；同一术语全文只解释一次。
   - 公式：逐符号说明 + 用大白话翻译整条公式在说什么。
   - 概念页存放在**各区块文件夹下的 `概念汇总/`**（同 AI运维），页面格式：`# 术语（英文）` → 一句话定义 → **通俗解释（研0 版）** → 关键要点 → 相关概念 → 回链论文笔记。
   - 全 vault 概念索引：`概念索引.md`（本科毕设根目录）。
7. 图必须有图解：每张嵌入图 `![[N-FigK_pP.png]]` 下方除斜体一句话图注外，紧跟「**图解**」段落：图里画了什么、怎么看（坐标轴/颜色/箭头含义）、读图结论、和毕设的关系。未提取的图用文字图解并注明。
8. 语体沿用 AI运维 笔记：中文叙述、术语保留英文原文、有页码出处、结论明确不含糊。
9. 每篇笔记末尾固定一节 `## 怎么用 & 怎么做（研0 版落地清单）`（2026-11-16 新增）：
   - 首行给思维导图入口：`> 思维导图：[[N思维导图.canvas]] · 总览：[[毕设论文总导图.canvas]]`；
   - **什么时候翻这篇**：一句话定位毕设时间线（开题/调研/实现/测试/写作哪一阶段用）；
   - **落地动作**分三小块：`在 Ubuntu 22.04 上`（具体命令、包名、配置）、`在树莓派上`（角色与复现点）、`C++ 实现要点`（库、数据结构、函数级提示）——只给可执行条目，不重复「对毕设的帮助」的论证性内容。
10. 每篇论文配一张思维导图 `N思维导图.canvas`（2026-11-16 新增，与笔记同文件夹）：
   - 结构：中心节点（论文短名+出处）→ 六个固定分支：**问题**（红 1）/ **方法**（橙 2）/ **关键机制**（青 5）/ **关键数字**（黄 3）/ **毕设价值**（绿 4）/ **落地动作**（紫 6）；
   - 分支下挂短语级叶子节点（每条 ≤2 行，不给段落）；另放一个 file 节点链到精读笔记；
   - 画布内容是笔记的压缩视图，**改笔记须同步改画布**。
11. 全库总览画布：根目录 `毕设论文总导图.canvas`（四个区块 group → 论文 file 节点 → 任务书 1–6 映射 + 故事线箭头）。

## 维护规则

- 新增论文：先在 [[论文地图]] 登记 → 建文件夹 → 写笔记 → 更新所属区块 `A-综述.md` 与 `X-知识图谱.canvas`（加一张文件卡 + 一张解说卡）；新术语随手在区块 `概念汇总/` 建页并登记进 [[概念索引]]。
- 新增规范/标准类资料（MQTT 规范、RFC 等）：同样先在 [[论文地图]] 的「规范资料」区登记 → 建文件夹 → 写精读笔记（沿用笔记规范，按章节而非页码顺序组织，加「哪些部分可以等」三档分类）；不要求更新区块 canvas。
- 淘汰论文：不删除，移入 `D可靠性容错与安全/../_archived/`（本科毕设/_archived/）并在论文地图标注。
- 本科毕设内临时脚本、中间产物放 `.zwork/`（Obsidian 不索引），用完可清理。
- PDF 只读不改；笔记是唯一加工产物。
