# MQTT（消息队列遥测传输）

**一句话定义**：OASIS 标准的轻量发布/订阅消息协议，专为不可靠网络与间歇连接设计，跑在 TCP/IP 上。

**通俗解释（研0 版）**：像小区的公告栏加广播站：设备（温度计）往公告栏贴一条「23 ℃」（publish），所有订阅了这个主题的居民都能收到。最小报文只有 2 字节，特别适合算力弱、电池小、网络差的设备。

**关键要点**
- broker 居中：publisher 发消息给 broker，subscriber 按 topic 订阅，一次 publish 扇出到所有订阅者（论文2 p.10）
- QoS 0/1/2 三档送达保证，级别越高 broker 开销越大（论文2 p.10–11）
- 证据数字：最小包 2 字节 vs HTTP 头 200 B–2 KB（论文2 p.2）；功耗 HTTP=5.3×MQTT（p.22）；十大云平台全部支持（p.7）
- 短板：不支持大 payload、仅 D2C、无动态发现、broker 是 SPoF、TCP 长连接限制设备休眠（论文2 p.27）
