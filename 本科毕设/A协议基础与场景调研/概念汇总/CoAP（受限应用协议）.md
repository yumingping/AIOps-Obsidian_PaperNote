# CoAP（受限应用协议）

**一句话定义**：面向受限设备（8 位 MCU、小内存）的 REST 风格 web 传输协议，跑在 UDP 上，最小二进制头 4 字节。

**通俗解释（研0 版）**：如果把 HTTP 比作挂号信（正式、信封大、来回确认多），CoAP 就是把「网页访问」改写成明信片——格式精简到 4 字节头，专为算力弱、电池小的设备设计，风格和 HTTP 一脉相承。

**关键要点**
- CRUD 操作映射 HTTP 方法，状态码也类 HTTP（2/4/5 开头）（论文2 p.8–9）
- 可靠性靠 CON 消息重传直到收到同 message id 的 ACK；安全用 DTLS（论文2 p.9）
- 只支持 D2D、不做移动性管理：设备跨网换 IP 后系统找不到它，NAT 后资源发现失效（论文2 p.22–23）
- 实现极小（CoAP-Lite 约 14 KB）；小 payload 高效、大 payload 恶化（论文2 p.3, 25–26）
