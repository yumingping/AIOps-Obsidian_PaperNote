# Cloudlet（微数据中心）

**一句话定义**：部署在移动设备附近（商场、校园等）的小型数据中心，作为移动设备与云之间的 edge 层。

**通俗解释（研0 版）**：云是省城的大仓库，cloudlet 是你家附近的小型仓储点——规模小但就在身边，取送都快。论文1 把它列为 edge 的典型形态之一。

**关键要点**
- 位于移动设备与云数据中心之间的 micro data center（论文1 p.2）
- 实测：卸载可穿戴认知辅助应用，响应时间改善 80–200 ms，能耗降 30%–40%（论文1 p.3）
- 毕设的边缘网关承担类似角色，是消息中间件的宿主位置
