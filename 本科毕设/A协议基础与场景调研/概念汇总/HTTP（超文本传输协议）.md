# HTTP（超文本传输协议）

**一句话定义**：网页世界通用的无状态一问一答（request-response）应用层协议，IoT 中用作 REST 服务的事实标准。

**通俗解释（研0 版）**：像柜台服务：你递单子（request），柜台处理后给回执（response），一来一回。通用、能穿防火墙、工具链最全，但报文头大（未压缩 200 B–2 KB）、无 QoS，喂给低时延的关键任务不合适。

**关键要点**
- 无状态；内容协商使其能服务异构设备；主流版本 1.1（论文2 p.8）
- 十大 IoT 云平台全部支持；Eclipse 调查采用率长期居前二（论文2 p.7, 26）
- 劣势：header 大、时延高、文本编码、无 QoS、不易扩展（论文2 p.27）
- 分布式追踪工具链成熟（Zipkin/Jaeger 等）；非 HTTP 协议（MQTT/AMQP）的追踪支持几乎空白（论文2 p.19）
