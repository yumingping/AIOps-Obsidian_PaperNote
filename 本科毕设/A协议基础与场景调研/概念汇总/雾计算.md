# 雾计算

**一句话定义**：在路由器、网关等网络基础设施层就近做计算的模式，与边缘计算基本同义、侧重不同。

**通俗解释（研0 版）**：云是天上的云，雾就是贴地面的雾——还是同一套「远端算力」体系，但落到了离设备很近的位置。论文1 作者认为 edge 与 fog 两个词可以互换，只是侧重不同。

**关键要点**
- edge computing 偏 things（设备）侧，fog computing 偏基础设施侧（论文1 p.2）
- 工程语境常见「fog 网关」「本地 fog 环境」：指部署在本地网络设备上的边缘层（论文2 p.20–21）
- 毕设网关部署在本地区域时，即处于 fog 层
