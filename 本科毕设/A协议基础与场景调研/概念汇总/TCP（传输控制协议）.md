# TCP（传输控制协议）

**一句话定义**：传输层的可靠传输协议：靠序列号、确认（ACK）、校验和、重传保证数据完整、有序、不重。

**通俗解释（研0 版）**：像挂号信加签收：每一封都编号，对方签收了才算送到，丢了就补寄，顺序乱了能重排。代价是为了这些保证要做流控/拥塞控制，时延不可预测——论文3判断 TCP 保可靠（Req-5）但不实时（Req-4）。

**关键要点**
- 序列号 + ACK + 校验和 + 重传 = 送达/顺序/去重三保证（论文3 p.3）
- 流控与拥塞控制机制行为不可预测，拖累实时性
- 配 TLS 做传输层加密；MQTT/AMQP/XMPP/DPWS 都跑在 TCP 上
- 论文4实验中 MQTT 正是跑在 TCP 上，QoS 2 的四次握手叠加 TCP 重传共同影响时延/丢包
