# 端到端时延

**一句话定义**：一条消息从发出方到接收方收下所经过的全部时间。

**通俗解释（研0 版）**：快递从「寄件人发出」到「收件人签收」的总时长，中间所有驿站、运输、排队都算在内。论文4的口径：报文从 Subscribe server 经 broker 到 Publish client 沿途各段时间戳累差。实测：有线 0.03–0.14 s，无线 3G 0.4–1.0 s（差一个数量级）；payload>4,000 bytes 后分片增多、时延明显上升。

**关键要点**
- 测法：沿途时间戳累差（论文4 p.2）
- 时延排序 QoS 2 > QoS 1 > QoS 0；QoS 2 主因是四次握手（论文4 p.3 图4）
- 无线（3G）比有线高一个数量级，主因传输速度
- 与丢包强正相关（r>0.77，有线 QoS 2 达 0.991，论文4 p.4 Table I）
