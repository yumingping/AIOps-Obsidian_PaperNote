# QoS（服务质量）

**一句话定义**：消息协议中预先声明的送达承诺等级，约定「这条消息保证送到什么程度」。

**通俗解释（研0 版）**：寄快递的三档服务：QoS 0 是普通信件（丢了不赔，发一次完事）；QoS 1 是挂号信（没收到回执就反复寄，可能重复投递）；QoS 2 是对账式流程（确保恰好一次，最稳也最费事）。等级越高越可靠、开销越大。

**关键要点**
- MQTT QoS 0/1/2（论文2 Table 6, p.10–11）；级别在 Connect Flags 的 Will QoS 位（bits 4/3）指定
- 级别越高 broker 保障开销越大：QoS 2 + 多订阅者是最重场景（论文2 p.10–11）；QoS 2 的机制缺陷是很多云平台不提供它的原因（p.23）
- 实测：本地 fog 环境 QoS 1 丢包是 QoS 0 的 6.2 倍（论文2 p.21）
- DDS 有 23 种 QoS 策略（论文2 p.13）；HTTP/XMPP 无 QoS（p.27–28）
