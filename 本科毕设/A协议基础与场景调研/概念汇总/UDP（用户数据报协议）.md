# UDP（用户数据报协议）

**一句话定义**：传输层的无连接传输协议：不保证送达、顺序、去重，但开销小、时延低、快。

**通俗解释（研0 版）**：像广播喊话：喊出去就算完成，没人确认收到、也不保证次序。换来的是没有慢吞吞的握手和重传流程，时间可预期——潜在实时可达的协议（DDS、OPC UA UDP、MQTT-SN）都选它，但可靠性要靠应用层自己补。

**关键要点**
- 简单、无可靠性与流控/拥塞控制（论文3 p.3）
- 潜在实时的前提：底层（如 TSN）与应用层补实时机制
- 配 DTLS 做加密；multicast 场景 DTLS 不可用是 OPC UA/DDS 的安全缺口
- QUIC = 基于 UDP 重建的可靠+低时延传输（RFC 9000）
