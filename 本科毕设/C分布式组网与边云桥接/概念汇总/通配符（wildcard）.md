# 通配符（wildcard）

**一句话定义**：订阅 topic 时可用的「万能牌」：+ 代表任意一层，# 代表其后所有层。

**通俗解释（研0 版）**：订频道时的模糊搜索：home/kitchen/+ 是「厨房里的任意一台设备」（只管一层）；home/kitchen/# 是「厨房里的一切、包括更深的子频道」（管到底）。万能牌用得越多，订阅覆盖的面就越宽，和其他订阅「撞车」（重叠）的机会也越大——这正是论文8 优化的空间。

**关键要点**
- 语法约束：只有 + / # 两种；# 若出现必须是最后一个字符（论文8 p.5）——这两条约束把包含判定从 NP-Complete 降到线性时间
- 单层 + 例：home/kitchen/+/status；多层 # 例：home/kitchen/oven/#（论文8 p.2）
- 通配符率越高订阅重叠越多：仿真设单层 + 概率 α、多层 # 概率 β=α/10（论文8 p.6）
