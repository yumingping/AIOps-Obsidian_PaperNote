# Subscription Flooding（SF，订阅泛洪）

**一句话定义**：broker 间分发机制之一：泛洪每条订阅，发布消息沿精确路径只发给需要的邻居。

**通俗解释（研0 版）**：先把「我要订哪些频道」的通知铺满全网每个邮局，此后每条消息只走「有预订的路」精准投递。订阅贵一次，之后每条发布都省——发布量大时划算；订阅频繁、兴趣分散时铺路本身就成了负担。

**关键要点**
- 每个 broker 维护「topic → 感兴趣的邻居（客户端+broker）」映射（论文8 p.4）
- 退订处理 tricky：只要还有客户端或至少两个邻居需要，订阅关系不能撤；仅当无客户端且只剩一个邻居时可撤销（论文8 p.4）
- 是否划算由 IBR 与 SPR 决定（式 5，拓扑无关，论文8 p.5）；实际场景长期偏 SPR 低，SF 常占优（论文8 p.6）
