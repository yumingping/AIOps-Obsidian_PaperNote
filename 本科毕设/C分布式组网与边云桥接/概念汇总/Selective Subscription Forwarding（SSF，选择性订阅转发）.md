# Selective Subscription Forwarding（SSF，选择性订阅转发）

**一句话定义**：论文8 提出的机制：转发订阅前先做 topic 包含判定，只转发未被已有订阅包含的订阅，使 broker 间订阅永不重复、永不重叠。

**通俗解释（研0 版）**：SF 是「见订阅就转发」，SSF 是「转发前先看一眼：这条订阅是不是已经被别人订过更宽的了？」——已被覆盖就不发。像接力传话时，前面的人已经把更大的范围喊过了，后面就不必重复喊。判定只花线性时间，几乎不增加计算负担，却把订阅流量砍掉一大截。

**关键要点**
- 每个 broker 维护 TI（topic→感兴趣邻居）、HT（下一跳感兴趣的 topic）、HS（实际转发过的 topic）三个映射，HS 与 HT 之差就是省掉的部分（论文8 p.4）
- 退订时要把被退订订阅覆盖的窄订阅补发回来，防漏报（论文8 Algorithm 1 第 13–22 行，p.4–5）
- 实验+仿真：订阅流量降 40%+、服务时延降 20%，计算开销不显著（论文8 p.1, p.8）；订阅互不包含时退化为 SF（论文8 p.5）
