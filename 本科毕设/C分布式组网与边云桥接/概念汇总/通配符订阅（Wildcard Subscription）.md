# 通配符订阅（Wildcard Subscription）

**一句话定义**：订阅时用 # 或 + 等通配符一次匹配一批 topic 的订阅方式。

**通俗解释（研0 版）**：普通订阅是'只订 3 号楼 502 的信'，通配符订阅是'3 号楼所有信我都收'：+ 匹配一层（factory/+/temp 匹配任何车间的 temp），# 匹配剩下所有层（factory/# 匹配 factory 下全部）。论文9 用它让桥接组件按数据源聚合：provider 下加新 hub 也不用改桥的配置，新流自动被通配符接住，还顺带缩短了 topic 名（15 vs 29 字节）。

**关键要点**
- + 单层通配、# 多层通配（MQTT 标准）
- 桥接按 provider 聚合订阅时，hub 增删无需改桥配置（论文9 AUT 1, p.5–6）
- 通配符订阅的 topic 名更短 → 实测延迟略低（论文9 RQ2 的 15B vs 29B 对比）
