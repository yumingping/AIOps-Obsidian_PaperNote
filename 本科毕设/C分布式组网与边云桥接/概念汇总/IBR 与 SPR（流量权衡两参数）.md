# IBR 与 SPR（流量权衡两参数）

**一句话定义**：IBR = 对某 topic 感兴趣的 broker 占比；SPR = 订阅总字节/发布总字节之比。两者决定 SF vs PF 谁省流量（式 5，拓扑无关）。

**通俗解释（研0 版）**：IBR 是「这条频道的消息有多少个邮局有人要」——兴趣越分散 IBR 越低；SPR 是「订阅通知相对消息本身有多重」。SF 划不划算 ≈ 两个数一加：式 (5) 为 T_SF/T_PF = (IBR×m−1)/(m−1) + SPR，小于 1 就划算，与网络形状无关，数一数就能判断。

**关键要点**
- 式 (5)：T_SF/T_PF = (IBR×m−1)/(m−1) + SPR；IBR 低 + SPR 低 → SF 省流量（论文8 p.5）
- 实测长期场景偏 SPR 低（订阅一次持续收消息），SF 常占优（论文8 p.6）
- 毕设测试用这两参数扫测试矩阵，比盲目调参更有解释力（论文8 p.5–6）
