# 分布式 broker 网络（distributed broker network）

**一句话定义**：多个 broker 各管一片设备、彼此连成网络协同分发的架构；消息必须能跨 broker 送达所有感兴趣的客户端。

**通俗解释（研0 版）**：不是一个大邮局包揽全国，而是每个社区一个邮局、邮局之间有运输干线。与「集群式 broker」（多实例同步复制、对外装成一个逻辑节点）不同：它是完全分布式、无中心也能工作的，关注点是消息怎么跨节点分发而不是数据复制（论文8 p.2）——这是论文8 与论文6 的分界线。

**关键要点**
- 论文8 三层架构：云 broker / 边缘 broker 层 / 设备层，边缘层承担主要处理与转发（论文8 p.2）
- 假设网络无环（loop-free）：有环要先用 MQTT-ST 等外部机制破环（论文8 p.3）
- 核心问题：跨 broker 消息分发机制的选择（PF/SF/SSF 谱系）（论文8 p.3–5）
