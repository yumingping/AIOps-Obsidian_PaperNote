# SO_REUSEPORT（端口复用）

**一句话定义**：Linux 3.9+ 的 socket 选项：允许多个监听 socket 绑定同一个端口号，内核把新连接自动分摊给它们。

**通俗解释（研0 版）**：像银行开多个相同号码的服务窗口，叫号系统自动把新顾客分给空闲窗口——每个窗口（线程）有自己的等候队列，不用所有顾客挤一个队再互相抢。muMQ 内核栈模式靠它实现「每核一个事件循环」。

**关键要点**
- 每个线程/每核有自己的 listening socket
- 内核层完成新连接的负载均衡，应用不用自己分发
- 多核 I/O 多路复用的关键开关
