# 事件循环（event loop）

**一句话定义**：一个「等事件 → 处理事件 → 再等事件」不停循环的线程，用少量线程处理大量连接。

**通俗解释（研0 版）**：像一个前台接待员盯着大厅：谁举手（连接上有数据到了）就服务谁，没人举手就歇着——而不是给每位客人配一个专职服务生（一连接一线程，连接多了线程切换把 CPU 耗光）。Mosquitto 用一个事件循环（单线程），muMQ 每核一个。

**关键要点**
- 单线程事件循环：简单、无锁，但吃不满多核（Mosquitto 45K msg/s 天花板，论文7）
- 每核一个事件循环 + 多监听 socket = 多核扩展的正解
- 「一连接一线程」（ActiveMQ）是反例：上下文切换开销重
- 事件驱动 + 异步 I/O 是高并发服务器的主流写法
