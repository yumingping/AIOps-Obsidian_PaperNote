# 故障注入与 MTTF、MTTR（fault injection）

**一句话定义**：故障注入：故意在系统里制造故障来考验容错能力；MTTF/MTTR：平均无故障时间 / 平均恢复时间，一对控制「故障节奏」的参数。

**通俗解释（研0 版）**：像消防演习：人为制造「着火」（断连），看系统能否按预案恢复。Toxiproxy 是夹在客户端与 broker 之间的「捣乱中间人」代理，可按指令掐断/延迟经过它的连接；MTTF=30 s 表示平均每 30 s 故障一次，MTTR=5 s 表示平均 5 s 恢复。用 TCP RST（直接掐线的「拔网线」方式）比优雅断开更接近真实掉线。

**关键要点**
- 故障到达用指数分布（泊松到达）模拟随机性
- uptime ≈ MTTF/(MTTF+MTTR)，论文7 约 85%
- 重连用相同 client Id 才能恢复 MQTT 会话、让 QoS 1/2 消息补投
- 毕设验证断线重连机制可直接复用此故障模型
