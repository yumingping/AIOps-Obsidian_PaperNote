# RSS（接收侧扩展）

**一句话定义**：网卡的硬件分流技术（receive-side scaling）：按规则把进来的数据包拆给多个 CPU 核各自处理。

**通俗解释（研0 版）**：像机场安检口按航班分流旅客，避免所有人都排同一个队。注意：论文7 里的容器内存指标 RSS（resident set size，常驻内存）与此重名但完全无关。

**关键要点**
- 硬件级负载均衡，让每核的包处理互不干扰
- DPDK/mTCP 路径的包 I/O 第一步
- muMQ-m 借助它把包分发到指定 CPU core
