# Kubernetes（K8s，容器编排系统）

**一句话定义**：自动管理大量容器的编排系统：负责容器在各机器上的部署、扩缩容、崩溃重启与网络入口。

**通俗解释（研0 版）**：Docker 把应用打包成标准化「集装箱」，K8s 就是港口调度系统：哪个集装箱挂了自动再拉起一个、负载高了自动多开几个、对外统一发门牌号。论文6 里 broker 以 pod（K8s 最小部署单位，一个「容器盒子」）为单位跑在 K8s 上，弹性伸缩由 CPU 阈值触发。

**关键要点**
- 论文6 用 stateful set/replication controller 跑 broker、metalLB 做负载均衡服务、helm chart 一键安装（论文6 p.7）
- autoscaling 关键发现：只对新连接生效，已有连接不迁移，恒定连接加压测不出水平扩展收益（论文6 p.10）
- 新 pod 启动时间 14.2–20.2 s：短于此的负载峰值只能靠垂直扩展扛（论文6 p.10）
