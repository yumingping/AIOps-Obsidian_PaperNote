```
- **标题**：英文原题（中文译名）
- **作者**：…（单位）
- **期刊/会议**：…（从 PDF 第一页/页眉读取，不确定就写"未确认"）
- **发表时间**：…年

> 页码说明：如 PDF 物理页码与印刷页码不一致，此处注明口径（笔记统一用 p.N = PDF 物理页码，正文引用期刊印刷页码时另注）。

## 一、preview/abstract（p.N）

（每个关键定义/机制/公式：**含义** + **为什么需要**；核心数字、结论加粗）
（关键处嵌图：![[N-FigK_pP.png]]，下一行 *图X（p.N）：一句话图注*）

## …

## 与其他论文的关系
（区块内 2–3 句 + 跨区块 1–2 句，用 [[N中文短名]] 双链指向同批论文笔记，文件名见下方清单）

2. …
```

## 硬性要求

- 中文叙述，术语/协议名/系统名保留英文（MQTT、QoS 0/1/2、broker、retained message、keep-alive…）。
- 每个实质论断带页码出处 `(p.N)` 或 `（p.N–M）`。
- 不编造：提取文本读不懂/缺失的部分如实写「PDF 文本提取此处不完整」，绝不臆测。
- 图：从 `图源目录` 选取 1–3 张最能代表论文核心机制的图，复制到论文文件夹并按 `N-FigK_pP.png` 命名（K 按论文中被选图的出现顺序 1,2,3…；P=该图所在 PDF 物理页码）。无法用提取图表达的关键图（矢量图/表格），正文用文字描述并注明「（p.N，未提取）」。
- 双链只用下方清单中的笔记文件名；不确定的概念不加链接，用粗体。
- 数学公式用 `$...$` 或 `$$...$$`。
- 笔记长度参照金标准：详读型，约 100–200 行；实验型论文重点记录实验设置、指标数字、结论。
