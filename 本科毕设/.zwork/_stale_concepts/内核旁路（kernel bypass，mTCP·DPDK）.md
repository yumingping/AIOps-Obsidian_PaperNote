# 内核旁路（kernel bypass，mTCP·DPDK）

**一句话定义**：让网络数据包绕过操作系统内核的 TCP/IP 栈、由应用程序在用户态直接处理的技术路线；mTCP 是用户态 TCP 栈，DPDK 是它运行所需的高速包 I/O 底座。

**通俗解释（研0 版）**：像快递不走分拣中心（内核）：寄件人（网卡）直接把包裹交给你的私人分拣员（应用线程），省去每次「进出分拣中心登记」的系统调用开销和排队（多核竞争）。代价：DPDK 的轮询驱动会一直满载吃 CPU（muMQ-m 恒定 1600%），功耗高；且 broker 的发布/订阅连接天然分不到同一个核，mTCP 为 web server 设计的多核优化用不上（论文5 §五 教训）。

**关键要点**
- DPDK 的 PMD（轮询模式驱动）直接从网卡收发包、不经内核
- mTCP 提供 BSD-like socket / epoll-like 接口，移植成本低（muMQ 只改约 90 行）
- 吞吐增益可观：muMQ-m 比 muMQ-k 最高 +154%、比 Mosquitto 最高 +538%
- PMD 忙轮询恒定吃满核，对电池供电的边缘网关不可接受
