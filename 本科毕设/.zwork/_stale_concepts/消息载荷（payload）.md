# 消息载荷（payload）

**一句话定义**：一条消息里真正要传送的数据内容（不含报文头等协议开销），大小以 bytes 计。

**通俗解释（研0 版）**：快递里的货物本身，不算纸箱和面单。MQTT 协议层 payload 上限 256 MB（论文3），但论文4实测：超过 4,000 bytes 后网络分片增多、时延上升；无线链路 16,000 bytes 时丢包陡升——协议上限不等于实际可用上限，边缘/无线场景要给消息大小设更小的门槛。

**关键要点**
- 实验梯度：1,000/2,000/4,000/8,000/16,000 bytes（论文4 p.2–3）
- >4,000 bytes 分片增多 → 时延上升（有线）
- 无线 16,000 bytes 处丢包悬崖
- MQTT 协议 payload 上限 256 MB（论文3 p.4）
