# 负载均衡器（Load Balancer）

**一句话定义**：把请求/连接分摊到多台后端服务器、并在某台失效时绕开它的调度层。

**通俗解释（研0 版）**：银行大厅的取号机+大堂经理：客户（客户端）只面对一个入口，经理把人分到空闲柜台（broker），某个柜台停了（broker 失效）就把排队的客户引到其他柜台，客户只感觉'还是同一家银行'。论文10 用它监控 broker 存活、迁移 topic；毕设可用 nginx/HAProxy 的 TCP 健康检查实现同等功能。

**关键要点**
- 论文10：多个边缘低功耗 broker 挂在同一负载均衡器下，消除'单 broker 失效断网'，并防各 broker 越过带宽约束（p.3）
- 失效/过载两条路径：topic 迁移到可用节点，客户端无感（p.4）
- 论文10 未说明负载均衡器自身的冗余——它仍可能是单点（笔记检视层判断）
- 毕设落法：nginx/HAProxy TCP 健康检查 + broker 池，替代 BNS
