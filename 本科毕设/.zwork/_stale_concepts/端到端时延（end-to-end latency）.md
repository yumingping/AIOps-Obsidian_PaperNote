# 端到端时延（end-to-end latency）

**一句话定义**：一条消息从发布方发出、经 broker 转发、到订阅方收到的全程耗时。

**通俗解释（研0 版）**：像快递从下单到签收的总时长——中间任何一环（网络传输、broker 排队、协议握手）慢都会算进来。测法：发送方在消息里嵌时间戳，接收方用「到达时刻 − 发送时刻」计算；两端必须时钟同步（publisher 与 subscriber 同机共钟最稳）。

**关键要点**
- 需要时钟同步：论文5/7 都用同机部署共用时钟
- 报 p50/p95 而非只有均值，才能看清典型与最坏情况
- QoS 越高握手越多、时延越高（Mosquitto QoS 2 惩罚 3.6 倍）
- 论文5 用消息内嵌 32 字节时间戳实现
