# 丢包率（Packet Loss）

**一句话定义**：发出的一批消息中未被接收方收到的比例。

**通俗解释（研0 版）**：100 件快递丢了几件。论文11 发现丢包主因常不是协议或带宽，而是 broker 的宿主机算力被掐死：CPU 配额从 25% 放开到 100%，丢包率从 43.60% 降到 0.42%。

**关键要点**
- 论文11 定义：publisher 发出、subscriber 未收到的百分比
- 随 QoS 升高单调下降（0.77%/0.36%/0.19%）
- 500 Mbps + 最小队列时 QoS 0 丢包峰值达 22.71%
- 排查顺序：先查 broker 宿主资源，再怀疑协议
