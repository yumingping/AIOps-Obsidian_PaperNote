# 端到端加密（End-to-End Encryption）

**一句话定义**：只有收发两端能解密、中间节点只见密文的加密方式。

**通俗解释（研0 版）**：只有寄件人和收件人有钥匙的挂号信：快递员（broker）只送信封、看不到内容。MQTT 的 payload 可以这样做，但 topic 作为分拣依据必须明文。

**关键要点**
- 中间节点（broker）无法读内容
- 成熟方案：TLS/ABE 等可保护 payload
- 与链路加密的区别：TLS 到 broker 就解密，端到端则直到接收方才解密
