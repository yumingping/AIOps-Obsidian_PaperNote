# TCP（传输控制协议）

**一句话定义**：互联网底层的可靠传输协议，MQTT 消息最终靠它送达。

**通俗解释（研0 版）**：TCP 像挂号信制度：给每个字节编号、确认、丢了重发，保证数据完整有序到达。MQTT 是跑在 TCP 之上的应用层协议。

**关键要点**
- MQTT over TCP；QoS 0 时 RTT 退而用 TCP 层 ACK 测量
- Nagle 算法等 TCP 层优化会影响 MQTT 时延
