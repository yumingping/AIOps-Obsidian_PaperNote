# 一次性口令（OTP）

**一句话定义**：每个口令只用一次、用完作废的认证/命名思路（如动态验证码）。

**通俗解释（研0 版）**：网银短信验证码那种「一次一密」：就算被偷看，下一条又变了。论文12 借这个思路给 topic 起名——每个混淆 topic 用一次就换，broker 抓不到固定规律。

**关键要点**
- 与重放攻击相对：旧口令失效，截获也无法重放
- 论文12 D 方案：OTP 思想 + hash 链实现 topic 混淆
- 前缀碰撞（撞上别人的前缀）反而增加 broker 关联难度，可故意借高频前缀制造
