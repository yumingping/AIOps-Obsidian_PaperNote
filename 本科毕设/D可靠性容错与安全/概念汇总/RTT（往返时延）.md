# RTT（往返时延）

**一句话定义**：一条消息从发出到收到确认的来回耗时。

**通俗解释（研0 版）**：寄快递到收到「签收回执」的时间。论文11 按 QoS 分层定口径：QoS 1 算到收到 PUBACK、QoS 2 算到 PUBCOMP、QoS 0 没有应用层确认、退而用 TCP 层的 ACK——对比三档 QoS 的 RTT 时，要知道 QoS 0 的口径不在同一层。

**关键要点**
- 测量口径按 QoS 分层（PUBACK/PUBCOMP/TCP ACK），写实验报告必须注明
- 论文11 实测 RTT 随 QoS 升高单调上升，握手次数是主因
- 客户端数量是与 RTT 相关性最强的参数（10 客户端时均值 82 ms、标准差 293 ms）
