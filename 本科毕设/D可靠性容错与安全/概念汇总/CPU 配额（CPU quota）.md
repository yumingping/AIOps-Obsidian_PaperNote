# CPU 配额（CPU quota）

**一句话定义**：给进程限制可用算力的手段（限频、cgroup、cpulimit 等统称）。

**通俗解释（研0 版）**：给员工规定「每天最多干 4 小时活」。论文11 把 broker 的 CPU 上限频率掐到 25%/63%/100% 三档，用来逼出「算力不够时可靠性从哪里开始崩」：63%→25% 之间劣化最陡，25% 时极端场景丢包高达 43.6%。

**关键要点**
- 论文11 的 CPU 档位通过限制 broker CPU 上限频率实现
- 算力不足时消息不是变慢而是直接丢——丢包根因常在宿主资源而非协议
- 部署教训：边缘网关不要给 Mosquitto 进程设 CPU 限制
