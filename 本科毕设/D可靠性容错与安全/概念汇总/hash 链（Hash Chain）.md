# hash 链（Hash Chain）

**一句话定义**：把同一个 hash 函数反复套用得到的一串值：上一环的输出是下一环的输入。

**通俗解释（研0 版）**：反复折纸：每一道折痕都依赖之前所有折痕，没法跳步、也没法从最后一道折痕反推整条链（hash 难逆）。论文12 让发布方逐个「用掉」链上的值当 topic，接收方对收到的值再 hash 一次即可核对真伪。

**关键要点**
- hash 函数：任意输入→固定格式「指纹」，同输入必同输出、难反推
- 每环只用一次（一次性口令思想的载体）
- 链长按内存自选；内存紧张可只存种子现算，但每条消息要做 n 次 hash、更耗电
