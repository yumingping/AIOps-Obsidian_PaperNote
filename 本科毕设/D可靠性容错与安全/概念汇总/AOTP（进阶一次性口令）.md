# AOTP（进阶一次性口令）

**一句话定义**：论文12 实现并实测的 topic 混淆方案：OTP + hash 链 + 每步掺盐（随机多项式）。

**通俗解释（研0 版）**：给一次性暗号再加料：每生成一环暗号，先给上一环「掺一把随位置变化的盐」再 hash，让两条链即使同起点也走向完全不同，更难被统计分析关联。开局用一条加密消息发「对照表+多项式+链长」，之后每发一条消息用掉一个暗号当 topic；接收方剥前缀后在表里逐个试错还原。

**关键要点**
- 客户端侧实现、broker 零改动，兼容任何标准公网 broker
- 实测（RPi 2）：解混淆 1–13 ms，只占远程 broker 全程时延约 10%；ESP8266 上约 120 ms
- 试错法耗时取决于 topic 在映射表中的位置——按频率重排映射可显著优化
- 残余风险：统计侧信道分析与标准化 hash 被识别套路
