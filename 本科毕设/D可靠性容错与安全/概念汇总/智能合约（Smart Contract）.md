# 智能合约（Smart Contract）

**一句话定义**：部署在区块链上的程序：满足条件自动执行，其状态与执行记录由链保障不可篡改。

**通俗解释（研0 版）**：类比自动售货机：投币（发交易）→ 机器按固定逻辑出货（合约代码执行），谁也不能中途插手改规则，每次交易都有据可查。论文10 用三个合约当 MQTT 的'链上后端'：一个管多 retained 队列、一个管死信队列（DLX）、一个管域名解析——broker 收到特定消息就调合约记账，订阅者重连再调合约取回。

**关键要点**
- 合约状态 = 链上的键值存储（论文10：topic → retained 消息数组的字典，p.4）
- 调用 = 发一笔链上交易，需全网确认——上链路径慢且有费用，是论文10 未量化的最大隐患（笔记检视层判断）
- 提供数据完整性、不可否认性（p.2），但这些是安全属性，对容错并非必需
