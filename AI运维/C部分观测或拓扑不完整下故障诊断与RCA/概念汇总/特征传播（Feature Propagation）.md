# 特征传播（Feature Propagation）

**一句话定义**：通过最小化 Dirichlet 能量（相邻节点特征差异之和），无需训练（源自 Rossi et al. 2021，论文10 p.3）。

**通俗解释（研0 版）**：没装传感器的站点数据缺失怎么办？像热量在金属里扩散那样，让邻居的读数一点点「渗」过来：相邻节点本来就该差不多（电网电压尤其如此），反复取邻居的加权平均，空洞就被填上了。全程只是一条公式反复迭代，不用训练模型——相当于用热传导原理补全一张缺了格子的温度图。

## 关键要点
- Dirichlet 能量（论文10 式 4，p.4）：
$$\xi(X, G) = \tfrac{1}{2} X^\top \check{\Delta} X = \tfrac{1}{2}\sum_{ij} \check{a}_{ij}(\mathbf{x}_i - \mathbf{x}_j)^2$$
- 梯度流 $\dot{X}(t) = -\Delta X(t)$（可测节点固定），前向差分离散化得迭代扩散方程（式 6）——每步把未测节点特征向邻居加权平均拉拢。
- 物理依据：线路阻抗导致相邻母线电压相近 → 图平滑假设在电网电压上成立。
- **论文10 的扩展（EFP）**：度-1 未测节点只有一个信息源，收敛后特征 ≈ 复制邻居，反而加剧同质化；解法是把它们的邻接行换成 $\hat{A}^k$ 的 k 阶子块、扩大感受野（式 3；33 母线 k=3、119 母线 k=6）。
- 对照：论文7 用**可训练的 GNN** 做同类插补（目标是时间轨迹而非静态特征），且以「下游定位失败率」而非重建误差论英雄。
