# 微服务根因分析（microservice RCA）

**一句话定义**：微服务发生故障（failure）后，从多源遥测数据中定位故障根源（fault，如 CPU 过载、内存泄漏、网络断连）的过程；输出通常是排序的根因服务列表（粗粒度）和根因指标（细粒度）。

**通俗解释（研0 版）**：网购突然卡死——是支付服务挂了，还是数据库连不上？RCA 就是在一堆喊「我出问题了」的服务里，揪出那个最先出事的。像医院查明多名病人同时呕吐、源头是食堂某道菜，最后交出一份按嫌疑大小排好序的名单。

## 要点
- 术语链：fault（根因）→ failure（功能失效）→ anomaly（可观测症状）（论文9 p.3）。
- 粗粒度 = 根因服务；细粒度 = 具体指标/日志/trace（论文9 p.3）。
- 两大路线：依赖调用图的（PDiagnose、CIRCA、Topo-MFP 等）vs 不依赖调用图的（BARO、CausalRCA、论文9 TORAI）。
- 评价常用 AC@k / Avg@k（论文9 p.11）、Hit@K / MAP@K（论文12 p.15）。
