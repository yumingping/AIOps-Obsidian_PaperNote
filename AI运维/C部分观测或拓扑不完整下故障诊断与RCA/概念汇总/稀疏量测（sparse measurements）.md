# 稀疏量测（sparse measurements）

**一句话定义**：量测装置（PMU/传感器）只覆盖部分节点（如装置密度 30–70%）时的观测状态——配电网的现实约束，因为全覆盖的设备与通信成本过高（论文10 p.2）。

**通俗解释（研0 版）**：在电网每个节点都装监测仪太贵，于是只装一部分（比如三到七成）——就像全城只在主要路口装摄像头。没装的位置读数是空的，算法得先把缺的数据补上，或者学会在缺数据的情况下照样破案。

## 关键要点
- 后果一：无量测节点特征缺失（论文10 直接置 0，p.3）→ 需要 [[特征传播（Feature Propagation）]] 或 GNN 插补。
- 后果二：可测节点的邻居大多也没量测，邻域信息贫瘠，GNN 聚合价值被稀释（论文10 p.1）。
- 论文10 的应对：EFP 补全 + 密度 30/50/70% 三档实验，密度越低补全收益越大（图 8，p.8）。
- 论文7 的对应概念是「部分可观测」：$K$ 台 PMU、$U$ 个盲区母线，观测比例低至 36% 时线路定位成功率仍约 75%（p.18）。
- 布点优化：在预算 $K$ 固定时选择装置位置（论文7 Algorithm 3 的 backward stepwise，$K=70$ 时组合数约 $1.02\times10^{35}$，p.13）。

## 在本部分论文里的角色
- 论文10 的标题级问题；论文7 的核心设定；论文8 中则表现为「告警流数据缺失」（时间戳抖动、事件丢失）。
