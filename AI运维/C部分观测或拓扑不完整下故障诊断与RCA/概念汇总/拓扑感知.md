# 拓扑感知

**一句话定义**：把服务依赖拓扑作为结构信息纳入学习/推断过程，但把它当作**可被数据证据覆盖的软先验**而非硬约束的建模思想。

**通俗解释（研0 版）**：查案时地图说「这两家店挨着，案情可能相关」，但证词可以推翻地图的猜测。拓扑感知就是把服务依赖图当参考地图而不是铁律：图上相邻只减轻「怀疑」，真正的定罪交给数据证据。论文12 证明这种「软用图」比「硬按图抓人」更准。

## 要点
- 论文12 的实现：拓扑感知软稀疏先验 $L_{topo}=\sum_{i,j}\rho_{ij}|A_{prop,ij}|$，拓扑相邻对罚 $\rho_{in}=0.10$、远离对罚 $\rho_{out}=1.00$（p.10、p.16）；$A^{topo}_{ij}$ 还直接拼进传播分数的 MLP 输入（p.9）。
- 效果证据：Topology-RWR（raw 拓扑 + 反向 RWR）Hit@1 0.724/0.824 < Topo-MFP 0.872/0.901 → 拓扑有用但需多模态证据增强（论文12 p.18–19）；λ₂ 过大性能反降 → 拓扑约束过强会压死数据证据（p.20）。
- 对立面：论文9 TORAI 证明完全不用拓扑也能高准确率（盲点场景下更稳）。
- 与 B 部分呼应：B 部分在不完备观测下重构「真图」；拓扑感知路线不追求真图，只学「对诊断有用」的图。
