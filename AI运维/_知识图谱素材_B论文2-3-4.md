## 论文2：Reconstructing Networks with Unknown and Heterogeneous Errors

**元信息**：Tiago P. Peixoto，*Physical Review X*（PRX），2018 年 10 月。

**核心问题（不可靠形式）**：网络数据以[[邻接矩阵]]（adjacency matrix）形态给出，含假阴性（false negative，漏边）与假阳性（false positive，假边），且误差率 $p,q$ **未知、可逐边异质**（$p_{ij},q_{ij}$），多数情况下只有单次测量、无重复观测、无误差标注。

**方法骨架**：
1. 贝叶斯框架：网络生成模型（[[随机块模型（SBM）]] → [[DCSBM（度修正随机块模型）]] → [[HDCSBM（层次度修正随机块模型）]]）+ 噪声测量模型（二项分布，Beta 共轭先验）耦合，对 $p,q$ 解析边缘化（integrate out）。
2. 不取 MAP 单点，用 [[马尔可夫链蒙特卡洛]]（MCMC / Metropolis-Hastings）采全后验系综，以 [[最大边缘后验估计（MMP）]]（阈值 1/2 是推导出的最优值）取「共识」网络。
3. 关键洞察：带噪声观测一个 SBM 等价于无噪声观测另一个 SBM（$\omega'_{rs}=(1-p-q)\omega_{rs}+q$）；误差率被结构异质性「夹住」——单次测量 + 未知误差也能重构。
4. 异质误差模型要求 $n_{ij}>1$（多次测量），单次测量下异质性会被误吸收进结构；并支持纳入外部逐边不确定性 $Q_{ij}$。
5. 复杂度 $O(\langle k\rangle V+M)$，可处理百万级边（graph-tool 实现）。

**关键结果**：
- 模拟实验中绝大多数参数下 $S(\hat A,A^*)>S(x,A^*)$：单次测量重构即系统性优于原始数据；噪声大小本身可被推断（$q$ 比 $p$ 准）。
- C. elegans 神经网络：推断 $(\hat p,\hat q)=(0.41,6\times10^{-5})$——近一半真边被漏记；9/11 网络中推断出的 Atta–al-Shehri 未记录边后验概率 0.48，被独立新闻报道佐证。

**与其他论文的关系**：[[1缺失与虚假交互及复杂网络重构|论文1]]（Guimerà & Sales-Pardo, PNAS 2009）是贝叶斯 + SBM 重构的奠基工作（漏边+假边、输出边可靠性排序）；本文是其扩展——唯一同时做到单次测量 + 误差未知 + 误差异质 + 层次社区 + 任意指标误差棒。[[3从不可靠数据中贝叶斯推断网络结构|论文3]] 由 Peixoto 担任编辑，同一学派姊妹工作（论文3 换用混合模型 + HMC，放弃解析积分）。与论文4 同属「把缺失/误差当隐变量」的贝叶斯传统，但论文4 观测连续图信号、用 EM 最大化。与 C 区故障诊断论文暂无直接引用关系；其「观测缺失与观测为零必须分开记录、不确定性作为一等公民传播」的原则可对照 C 区的告警数据质量假设。

**对 AI 运维的启发**：
1. 拓扑/依赖数据（trace、日志共现）直接当真 = 偷偷假设了它比实际可靠；「没采集到」≠「采集到没有」，两类缺失要分开建模。
2. 误差率可从结构异质性反推：只要服务依赖图有足够强的模块结构，单次不完整观测也能重构并给出置信度。

## 论文3：Bayesian Inference of Network Structure from Unreliable Data

**元信息**：Jean-Gabriel Young, George T. Cantwell, M. E. J. Newman，*Journal of Complex Networks* 8(6), cnaa046，2020 年；代码 https://github.com/jg-you/noisy-networks-measurements（[[Stan（概率编程语言）]] 实现）。

**核心问题（不可靠形式）**：观测数据是**任意格式**的间接证据——计数、时间序列、非对称问卷提名、节点属性——并不直接告知边是否存在；误差的性质与大小均未知。传统做法直接拍阈值，等于默认「数据就是网络」。

**方法骨架**：
1. 全贝叶斯通用框架，只需三个建模选择：数据模型 $\mu_{ij}(k,\theta)$（有边/无边时分别测到什么）、网络先验 $\nu_{ij}(1,\theta)$（可插 [[Erdős–Rényi随机图]]、软 [[配置模型]]、[[随机块模型（SBM）]] 等）、参数先验 $P(\theta)$；联合后验逐对因子化。
2. 关键 trick：把 $\sum_A$ 搬进逐对乘积（[[混合模型]] 形式），[[哈密顿蒙特卡洛]]（HMC）只采连续参数 $\theta$，再逐边独立按 $Q_{ij}$ 采网络——换模型不用重推公式，稀疏加速 $O(M\log n)$。
3. 自带 [[后验预测检验]]（posterior-predictive assessment）：[[KL散度]] 型差异度 + 参照分布给 p 值，理想约 0.5（太小=模型错，接近 1=过拟合）。
4. 输出是结构 + 参数的完整后验分布，边存在概率 = 采样频率。

**关键结果**：
- 海豚同伴网络：两类型泊松模型 $R^2=0.50$（失配），改成三连接强度（无/弱/强）后 $R^2=0.82$、$p=0.722$，参数 $\lambda_0\simeq0.02,\lambda_1=5.13,\lambda_2=21.97$。
- AddHealth 友谊网络：异质误差模型推断 $\langle\alpha\rangle\simeq0.76$（约 24% 真实友谊没被报出），$\langle\beta\rangle\simeq0.0065$，但精确率（precision）仅 0.2–0.75——报出的友谊里 25%–80% 是假的。

**与其他论文的关系**：[[2重构具有未知和异质误差的网络|论文2]] 作者 Peixoto 是本文编辑，同一脉络：二者都是「网络生成模型 + 噪声测量模型 + 全后验共识」。分工不同——论文2 花力气在结构先验表达力（DC/HDCSBM）与异质误差的 Beta 共轭解析积分；论文3 花力气在数据模型任意性与自动化（HMC 采连续参数），可扩展到几十万节点，代价是社区划分这类离散隐变量不好处理。对 [[1缺失与虚假交互及复杂网络重构|论文1]]：论文1 不显式建模测量误差、以链接预测为目标，本文是其误差建模的系统化。与 [[4从不完整图信号中学习图：从批量到在线方法|论文4]]：观测对象根本不同——离散边证据 vs 连续图信号；前者是「测量误差」问题，后者是「缺失数据 + 图学习」问题，正好覆盖 AI 运维「告警/日志是离散噪声证据」与「指标时序是连续缺失信号」两类场景。与 C 区故障诊断论文暂无直接关联；「稀疏网络里看精确率而非假阳性率」的教训直接适用于告警评估。

**对 AI 运维的启发**：
1. 极稀疏场景下假阳性率再小也会造出海量假边——评估告警/拓扑发现要盯 precision，不能只看 FP 率本身。
2. 「混合模型边缘化 + 通用 HMC 采连续参数 + 逐边解析采样」可复用到「大量独立小单元 + 少量全局参数」的推断问题（如故障根因传播建模）。

## 论文4：Graph Learning from Incomplete Graph Signals: From Batch to Online Methods

**元信息**：Xiang Zhang、Qiao Wang（东南大学），*Signal Processing*（Elsevier）Vol. 226, Art. 109663，2025 年卷期，2024-08-13 在线发表，DOI 10.1016/j.sigpro.2024.109663。

**核心问题（不可靠形式）**：观测对象是节点上的**连续图信号**（graph signal），部分节点信号**缺失**（缺失机制 MCAR/MAR/MNAR，缺 30% 是常态）；且数据流式到达、零延迟容忍，批量范式失效。

**方法骨架**：
1. 把缺失信号 $X_m$ 当**隐随机变量**，写成含隐变量的后验最大化（先验 = [[图信号平滑性]] $\mathbf x^\top\mathbf L\mathbf x$，生成模型 $\mathbf x\sim\mathcal N(\boldsymbol\mu,\mathbf L^\dagger)$），用 [[EM算法]] 求解：**E 步 = 条件高斯线性回归恢复缺失信号，M 步 = 更新图拉普拉斯** $\mathbf L$。
2. 批量算法 BEMGLID：M 步把缺失影响压缩进经验协方差 $\mathbf Q$，外层图学习模型可替换（换 $g(\mathbf L)$ 与正则 $r(\mathbf L)$）；实例化为平滑性模型（对数障碍防孤立节点 + 谱范数罚控稀疏），凸问题用 PDS 求解。关键点：E 步保留条件协方差，不把插补值当真值。
3. 在线算法 OEMGLID：充分统计量指数加权递归（遗忘因子 $\rho$）+ [[在线学习]] 一步投影梯度（IP-OGD），每时隙恒定延迟。
4. 理论：[[动态遗憾（dynamic regret）]] 上界归结为初始化误差 + 路径长度 $P(T)$（图变化速度）+ 梯度误差 $E(T)$（缺失造成的估计不确定性）；两者次线性则 regret 次线性。复杂度 $O(d_o^3+d_m^2d_o+d^2)$，低于基线的 $O(d^3)$。

**关键结果**：
- 批量合成实验（$T=100$，缺失率 0.1→0.5）：边 F1 约 0.93→0.89，全程优于最强基线 SigRepImp（约 0.88→0.82）；$d=1000$ 时比 JGLSR/JISG 快 3–6 倍。
- 在线跟踪：拓扑突变瞬间 ReG 弹到 ≈0.96 后快速回落到 ≈0.40，验证遗忘因子有效；MNAR 下 FS 从 ≈0.95 掉到 ≈0.885（超出 Assumption 2 适用范围）。

**与其他论文的关系**：与 [[1缺失与虚假交互及复杂网络重构|论文1]]、[[2重构具有未知和异质误差的网络|论文2]]、[[3从不可靠数据中贝叶斯推断网络结构|论文3]] 同一区块但观测对象根本不同：前三篇问「这条边到底存不存在」（离散边证据，不确定性来自测量过程），本篇问「缺失的信号值是多少、背后的图长什么样」（连续信号，不确定性来自采样覆盖）。共同内核都是把缺失/误差当隐变量：前三篇边缘化 + MCMC 采全后验，本篇 [[最大后验估计]]（MAP）+ EM 最大化，只给点估计 + regret 界——笔记指出互补方向：把 E 步换成后验采样即可同时拿到图与缺失信号的置信度。与 C 区故障诊断论文暂无直接引用关系，但「运维中恰恰在异常/超阈值时采不到数 = MNAR」是其最危险的失效模式，与 C 区的异常期数据完整性问题天然相关。

**对 AI 运维的启发**：
1. 「缺失 → 隐变量 → EM」+「E 步只是便宜的条件高斯回归」适合指标缺失/探针失联场景的在线拓扑跟踪；遗忘因子 $\rho$ 是「跟踪变化 vs 稳定」的显式旋钮。
2. 警惕 MNAR：故障期间恰恰是采集最容易失效的时段，运维数据管道要先保证缺失机制可近似为 MCAR/MAR，否则模型系统性失真。
