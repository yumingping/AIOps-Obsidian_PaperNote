
# 冲突集（Conflict Set）

**一句话定义**：部件集合 {c1,…,ck} ⊆ COMPONENTS，使得 SD ∪ OBS ∪ {¬AB(c1),…,¬AB(ck)} 不一致——"这组部件不可能全都正常"（Reiter 定义 4.1, p.67）。

**通俗解释（研0 版）**：像用排除法找坏灯泡：一串彩灯不亮，你能立刻断定「这串灯不可能全都好」——这一串就是一个冲突集。此时还不知道具体哪个坏了，但已经把嫌疑圈定在这几个人里；而且只要有更大的圈，它自动是冲突集，所以只需记最小的那些圈。

**关键要点**
- 来源：de Kleer 1976 首创，Reiter 吸收进公理体系。
- 单调性：冲突集的超集自动也是冲突集 → 只需维护**极小冲突集**（Reiter p.67–68；GDE 的"conflict recognition 目标 = 找全极小冲突", 论文14 §2.3）。
- 电路例：三乘两加电路的两个极小冲突 ⟨M1,M2,A1⟩ 与 ⟨M1,M3,A1,A2⟩（三篇论文通用例子）。
- 由测量**新产生**的冲突集（Hou 定义 3.2, p.288）：加入 H 之前一致、之后不一致的集合——增量测量理论的核心对象。
- 识别方式：Reiter 用定理证明器记录反驳中出现的 AB 实例；GDE 沿依赖链回溯撞值处；Hou 用剪枝 cs-tree（32→14→9 次调用, p.315）。
