
# 最小命中集（Minimal Hitting Set）

**一句话定义**：对集合族 𝒞，H 与族中每个 S 都相交（H∩S≠∅）即为命中集；无真子集也是命中集则为最小命中集（Reiter 定义 4.3, p.67）。

**通俗解释（研0 版）**：每条冲突集相当于一个证人说「嫌疑人在这几个人里，至少有一个」。坏部件名单必须把每个证人的圈子都戳中（至少包含其中一人）；能满足所有指认的最短名单，就是最小命中集——也就是最可能的故障组合。

**关键要点**
- **核心定理**（Reiter 定理 4.4, p.67）：Δ 是诊断 ⟺ Δ 是全部（极小）冲突集的最小命中集。诊断问题由此变成组合数学。
- 计算结构：**HS-tree**（Reiter 定义 4.6, p.69）——根标一个冲突集，节点标与路径边标号不相交的冲突集，√ 节点的路径标号即命中集；配三个剪枝/复用手段（标签复用、关门、冗余边删除）。
- GDE 对应物：极小候选在子集-超集格上划边界，增量更新规则（旧候选 + 新冲突中一元素）= 增量求命中集（论文14 §2.5）；Hou 定理 3.13/3.15 证明其正确性。
- 与 Reggia GSC 集合覆盖模型的关系：诊断 = 观测表现的极小覆盖（Reiter 定理 7.1）；GDE（论文14 §6.6）与 Hou（p.326）都指出其 irredundant cover 对应极小候选/命中集。
