
- **标题**：Diagnosing Multiple Faults（诊断多重故障）
- **作者**：Johan de Kleer（Xerox PARC 智能系统实验室）、Brian C. Williams（MIT AI 实验室）
- **期刊/会议**：Artificial Intelligence, Vol. 32（与论文13 同期）
- **发表时间**：1987 年（Received September 1985, revised July 1986；期刊页 97–130）

## 一、preview（p.97–99）
### 痛点 / 已有方法为什么不行
#### 1. 以往的 [[基于第一性原理的诊断|model-based 诊断]]几乎都默认**单故障**
- LOCAL、SOPHIE、DART、Davis 的系统都用"一个故障解释所有症状"假设；候选生成就退化成冲突集求交。
- **这不行！** 一旦考虑多故障，候选空间随故障数**指数爆炸**（n 个部件 2^n 种组合）。
#### 2. 传统[[概率诊断]]需要海量条件概率
- 医学序贯诊断（Bayes 规则）中，10 个假设 + 5 个二元测试就要 2420 个条件概率（p.127）；工程上根本拿不到。
#### 3. 没有系统的"下一步测哪里"理论
- SOPHIE 用的是 ad hoc 的半分法（half-split）。

### 新方法（一段话）
实现了一个通用诊断引擎 **[[GDE 通用诊断引擎|GDE]]（general diagnostic engine）**，把候选表示为**极小违反假设集合**，用 [[基于假设的真值维护]]（ATMS, assumption-based truth maintenance）增量地做冲突识别与候选生成，天然支持任意多个并发故障；再从设备结构 + 部件先验故障率**推导出**候选的条件概率（不用人工统计），用**最小熵**准则选下一个测量。已在数字电路排障域大量测试。

**关键 trick**：候选 = 假设集合的违反模式 → 冲突与候选都只需维护**极小**元素（子集-超集格 lattice 上的边界），指数空间被隐式压缩。

## 二、introduction（p.97–99）
1. 现实痛点：诊断 = 找"模型与实物（artifact）的差异"。排障时模型对、实物错 → 差异即部件故障；理论形成时实物对、模型错 → 差异即待修模型。证据通常不能唯一确定差异，所以诊断必然是**两阶段**的：先找全部可能差异，再**提议测量**（[[主动测量与诊断消歧]]）逐步收缩。

### 本文贡献（摘要，p.97）
（原文此节内容在 p.97，此处为理解方便放在 introduction 末尾）
1. 支持**多故障**诊断；候选以极小违反假设集合表示，效率高。
2. 诊断过程**增量式**，利用诊断的迭代本性。
3. 诊断与行为预测**彻底分离** → 领域无关、推理引擎无关（约束传播、归结等都能当预测器）。
4. 模型预测 + 序贯诊断结合，**主动提出测量**以定位故障；所需条件概率由结构与部件模型算出。
5. 把概率与信息论装进 ATMS 的 context 机制。

## 三、诊断理论：症状 → 冲突 → 候选（p.100–106）
1. **基本预设（§1.2, p.100）**：测量不影响设备；测量值恒定；部件故障后输入输出分布随机（不含信息）；**故障部件不必然表现故障**（可能在这组输入下正常）——这一点决定了后面概率处理的形态。
2. **症状（symptom, §2.2）**：预测与观测（或两个预测之间）的任何不一致。例：输入 A=3,B=2,C=2,D=3,E=3，推出 F=12，实测 F=10。

![[14-Fig2_p4.png]]
*图2（p.100）：贯穿全文的例题电路——三个乘法器 M1–M3、两个加法器 A1–A2，输入 A–E = 3,2,2,3,3，输出 F=10、G=12 与期望值 12/12 的偏差引出全部冲突与候选分析。*

3. **冲突（conflict, §2.3）**
    - **含义**：支撑某个症状的一组假设（[[冲突集（conflict set）]]），至少一个必假。电路里即"**不可能同时都好**"的部件集合：F=10 ⇒ ⟨A1, M1, M2⟩（记号：⇒ 由…推出；⟨·⟩ 角括号包一组部件假设，此处表示一个冲突，下同）。
    - **为什么需要**：因为推理对假设单调，冲突集的超集自动也是冲突 → 整个冲突空间可由**极小冲突**完全表示。冲突识别的目标 = 找全极小冲突。
4. **候选（candidate, §2.4）**
    - **含义**：候选（[[候选诊断（candidate discrimination）]]）[.]（方括号记法：括号内列出被假设为坏的部件，如 [A1] = 只有 A1 坏；空括号 [ ] = 一切正常，下同）是一个假设集合：集合内假设为假（部件坏），未提及的为真；它能与**每个**冲突相交（解释所有症状）。n 部件初始候选空间 2^n（例中 32 个）。
    - 候选也满足"超集仍是候选"→ 只需维护**极小候选**，它们在子集-超集格上划出一条边界（图3）。

![[14-Fig3_p8.png]]
*图3（p.104）：例题电路的初始候选空间——32 个候选构成的子集格，底部 [ ] 表示一切正常。*

5. **增量候选生成（§2.5, p.104–106）**
    - **含义**：新极小冲突到来时，每个与之不相交的旧极小候选被替换为"旧候选 + 新冲突中一个假设"的若干超集，去除被包含/重复者。
    > 人话：新冲突来了，把所有与它不相交的旧候选各"补一个新冲突里的嫌疑"变成更大的候选——旧候选已躲开所有旧冲突，只能靠拉进新冲突的成员来解释新症状。
    - 例：冲突 $C_1$（conflict 1，第 1 个冲突，下同）=⟨A1,M1,M2⟩ 消灭 [ ]，产生 [A1]、[M1]、[M2]；冲突 C2=⟨A1,A2,M1,M3⟩ 消灭 [M2]，最终极小候选 = [A1]、[M1]、[A2,M1]、[M2,M3]——**与论文13 全加器同构，正是 Reiter 的"[[最小命中集（minimal hitting set）]]"**。
    - 三条好性质：候选一旦被消灭永不复活；出现在所有极小候选中的假设必然坏；单故障假设 ⟺ 全部候选都是单元素 ⟺ 冲突集求交。

![[14-Fig4_p9.png]]
*图4（p.106）：两次测量后候选格的边界移动。C1、C2 两条线逐级抬高极小候选，圈出者为幸存极小候选。*

## 四、冲突识别与推理架构（p.106–109）
1. **朴素做法**：逐个环境 $ENV$（**ENV**ironment，环境——一组"哪些部件被假设为坏"的组合，下同）调一致性测试 $C(OBS, ENV)$（给定观测 $OBS$（**OBS**ervations，观测集，下同）与环境 ENV，检验是否矛盾）。**这不行！** 环境数量指数。
2. **五个精化（§2.6, p.106–108）**：
    1. 利用极小性：从空环境自底向上搜，环境不一致即为极小冲突，超集不再探索；
    2. 测量的单调性：缓存 P（预测推断步骤，原文记号，下同）的结果，新测量只做增量推断；
    3. 假设的单调性：环境变大预测集只增不减，子环境结果直接复用；
    4. 消灭冗余推断：真值维护记录依赖，任何推断不执行第二次；
    5. 利用稀疏性：电路本来就设计成部件交互稀疏，只考察"有新推断"的环境。
3. **支撑环境（§2.7）**：每个预测值 V 带上使它成立的极小环境集合 ENVS(V)（**ENV**ironment**S**，使 V 成立的极小环境集合，下同）。两个不同值撞在同一变量上 = 症状，沿依赖链回溯即得冲突。**预测器可以不完备**——后果只是少发现冲突、少消灭候选，**绝不会错杀候选**（p.109）。这是 GDE 工程上极其重要的性质。
    > 人话：预测器漏推只是少抓到一些冲突（少排除一些候选），但绝不会把好的部件错判成坏——宁漏勿错，这是 GDE 敢用不完备推理的底气。

## 五、电路诊断：约束传播实例（p.109–112）
1. 电路 M1:X=A×C, M2:Y=B×D, M3:Z=C×E, A1:F=X+Y, A2:G=Y+Z；输入 3,2,2,3,3。
2. 传播带环境标注：⟨X=6,{M1}⟩, ⟨F=12,{A1,M1,M2}⟩…；测得 F=10 ⇒ 症状 ⇒ 极小冲突 ⟨A1,M1,M2⟩；测得 G=12 又从另一路径推出 G=10 ⇒ 极小冲突 ⟨A1,A2,M1,M3⟩。
3. 两个极小冲突 → 四个极小候选 [A1]、[M1]、[A2,M1]、[M2,M3]（p.106/112）。
4. **任意方向传播**：约束不分信号流向——减法器虽不能反向工作，但由输出可反推输入（p.111）。

## 六、序贯诊断：最小熵选测量（p.112–121）
1. **可能的测量（§4.1）**：GDE 数据库里每个变量 x_i（第 i 个变量，下同）的每个预测值 v_ik（变量 x_i 的第 k 个预测取值，下同）及其支撑环境现成可用。测 x_i 得 v_ik 时，与 v_ik 不同的值的支撑环境全变冲突 → 每种结果的候选空间缩减**可预先算出**。记 R_ik = 测得 v_ik 后剩余候选，S_ik = 其中必然 x_i=v_ik 的，U_i = 不预测 x_i 的（"未承诺"候选），R_ik = S_ik ∪ U_i。
2. **前瞻 vs 短视（§4.2）**：完整决策树分析代价爆炸 → 用**一步前瞻** + 香农熵：
$$H = -\sum_i p_i \log p_i$$
    $H$（香农熵，entropy，"不确定性/纠结程度"的度量，下同）、$p_i$（第 i 种结果为真的概率，下同）。H 估计"找出真候选的期望代价"（log p_i 比例于二分查找代价）；候选概率越分化 H 越小。
    > 人话：熵就是"还在纠结的程度"——候选概率越分散，熵越大，离查明真相越远。
3. **期望熵准则（§4.3, p.114–116）**：选使测量后期望熵最小的 x_i：
$$H_e(x_i) = \sum_{k=1}^{n} p(x_i=v_{ik})\, H(x_i=v_{ik}) + \sum_{k=n+1}^{m} \varepsilon_{ik} H_{U_i}$$
    记号：$H_e(x_i)$（e = expectation，测 x_i 之后的期望熵，下同）；$\varepsilon_{ik}$（epsilon，x_i 测出**未预测**取值 v_ik 时的概率修正项，下同）；$H_{U_i}$（未承诺候选集 U_i 上的熵，下同）；m（x_i 的可能取值总个数，下同）。
    化简为 $H_e(x_i) = H + \Delta H_e(x_i)$，故只需最小化 $\Delta H_e(x_i)$（p.116）。
    > 人话：给每个候选测量打分——"测完之后平均还剩多少熵"。哪个测量让剩余熵最小就测哪个，等价于每步挑"最能把嫌疑名单对半砍"的测试。
    - 对未预测值：假设 m 个可能值均匀，$\varepsilon_{ik} = p(U_i)/m$，故 $p(x_i=v_{ik}) = p(S_{ik}) + p(U_i)/m$（p.115）。
    - 代价含义：ΔH 即"做完这次测量后，平均还需几次测量"的期望增量；GDE 给它 +1 保持为正，代价 1 = 没有信息，0 = 完美信息（p.116）。
4. **概率从哪来（§4.4–4.5, p.116–117）**：只需部件**先验**故障率 p(c)（厂商数据或统计），故障独立假设下候选先验：
$$p_i = \prod_{c \in C_i} p(c) \cdot \prod_{c \notin C_i} (1 - p(c))$$
    记号：$p_i$（第 i 个候选的先验概率，下同）；$C_i$（此处指第 i 个**候选**，注意与 §三.5、§五 中用作冲突编号的 C1、C2 记号不同）；$\prod$（连乘，下同）。
    > 人话：一个候选（某组部件坏）的先验概率 = 坏部件各乘其故障率、好部件各乘 (1−故障率)。条件概率不用查表：模型预测该值的候选给 1，预测别的值给 0，没表态的给 1/m。
    测量后用 Bayes 规则更新，且条件概率 p(x_i=v_ik | C_i) 只有三种取值：0（候选预测别的值）、1（候选预测该值）、1/m（候选不预测）——**全部由模型算出，不需要经验条件概率表**。
    - p(x_i=v_ik|C_i)=1/m 这个估计是可疑点，但 U_i 里多为低概率候选，实践中用 p(x_i=v_ik|C_i)=1 近似"很少影响所需测量次数"（p.118）。
5. **例子（§4.6, p.118–120）**：
    - 级联反相器 a=1（p=0.01）：各测量代价接近 1；测得 e=0 后最优点是**与前两次测量等距**的 c（二分法涌现！）；若 a 的故障率升到 0.025，最优点移向 b——**概率信息自动改变测量策略**。

![[14-Fig5_p22.png]]
*图5（p.118）：级联反相器实验电路，演示最小熵测量点的移动。*

    - 例题电路定位双故障（M2 出错 Y=B×C−2、A2 出错 G=Y×Z+2，两故障效果抵消）（§4.6.5, p.119–120）：初始最可能候选 [ ]（p=0.951），所有测量代价≈1；F=10 后 [A1]/[M1]/[M2] 各 0.323；G=12 后 [A1] 与 [M1] 各 0.478，X 是唯一能切开两者的测量；X=6 后 [A1] 达 0.942；Y=4 揭示 M2 必坏；Z=6 后收敛到 [A2,M2]（0.970）。
6. **实用化（§5, p.121–122）**：最可能候选本身必是极小候选，可用最佳优先搜索按概率序枚举、阈值截断；"代价 < 1−log 0.5 = 0.7"的首个测量是合理的二分启发；候选概率近 0.9 即可停（误诊代价高则上调阈值）。

## 七、与其他工作的比较（§6, p.122–128）
1. **对早期 model-based 系统**：LOCAL/SOPHIE/DART/HT 都限单故障或无概率；Davis 承认多故障扩展会指数爆炸，而 GDE 靠极小候选表示，实践复杂度随故障数呈平方/立方增长（p.122–123）。SOPHIE 有"corroboration"（证實正常）机制可从两头收缩候选空间，GDE 没有（p.124）。
2. **对 Ginsberg 反事实（§6.2）**：最相似可能世界 ↔ 极小候选，可对应但 Ginsberg 无测量/概率理论。
3. **对 Reiter（§6.3, p.125）**：术语映射 ¬AB(A1)（¬ 非；$AB$ 异常谓词，AB(A1) 为真即 A1 被假设为故障，见 [[系统模型 SD 与 AB]]）↔ 假设 A1 正常；Reiter 的诊断定义 = GDE 极小候选，冲突集 = GDE 冲突。差别在架构：Reiter 把冲突识别与候选生成交织以避免"本质相同反驳变体"的重复计算，GDE 因必须选最优测量而先算全极小冲突，同样避开这些变体且计算更省。
4. **对医学序贯诊断（§6.6, p.127–128）**：同一个 Bayes 规则，但 GDE 从模型**推导**条件概率、测试也在分析中自动产生，而不是先验给定——这是工程域相对医学域的结构性优势。
5. **对 Reggia 集合覆盖（§6.6）**：OSC 的 irredundant cover ↔ 极小候选；差别是 GDE 理论上把一切覆盖都当解释。

## 局限与启发（p.100, 118, 121–124, 127）
1. **预设很强**：测量不影响设备、值恒定、故障随机分布——直接排除触发器、间歇性故障、时变部件（p.100，作者自认是未来方向）。
2. **极小候选最坏仍指数**：稀疏性是经验性质而非定理；层级分解、按故障类别分层枚举是给出的缓解路线（p.123–124）。
3. **不完备预测的代价**：U_i 变大 → 期望熵估计失真；表达力受 x_i=v_ik 形式限制（不能表达 x≠1 之类，p.121）。
4. **无故障模型**：只用正确行为模型；后续 Sherlock（behavioral modes, IJCAI-89）与 XDE、GMODS 走向融入故障模式（p.124, 论文15 §7.2 亦述）。
5. **AI 运维映射**：GDE 就是"可观测性驱动排障"的祖师爷——指标/日志断言=测量，调用链拓扑=结构模型，"最小熵选下一个测量"直接对应今天告警根因分析里"下一步查哪个服务/打哪个点"的决策；ATMS 的 context 复用对应增量式根因计算中"别重复推断"的原则。
